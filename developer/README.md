# Developer Handbook

Welkom in de **Developer Handbook** van RZD Builder.

Deze map bevat persoonlijke ontwikkelkennis, hulpmiddelen, workflows, checklists, templates en technische notities die tijdens de ontwikkeling van RZD Builder zijn opgebouwd.

In tegenstelling tot de officiële projectdocumentatie in `docs/` is deze map bedoeld als praktisch naslagwerk voor de ontwikkelaar.

---

# Doel

De Developer Handbook ondersteunt de dagelijkse ontwikkeling door:

- veelgebruikte Git-opdrachten centraal te bewaren;
- AI-tools efficiënt te gebruiken;
- VS Code optimaal in te richten;
- terminalcommando's te documenteren;
- veelvoorkomende problemen en oplossingen vast te leggen;
- herbruikbare code-snippets te verzamelen;
- templates en checklists beschikbaar te maken.

Hierdoor hoeft kennis niet telkens opnieuw te worden opgezocht.

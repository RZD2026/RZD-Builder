# Git

Deze map bevat alle Git- en GitHub-gerelateerde kennis die wordt gebruikt tijdens de ontwikkeling van RZD Builder.

Het doel is om alle veelgebruikte opdrachten, workflows, strategieën en best practices op één centrale plaats te bewaren.

---

# Uitgangspunten

- Houd de Git-historie overzichtelijk.
- Gebruik duidelijke commitberichten.
- Werk altijd vanuit de laatste versie van `master`.
- Ontwikkel nieuwe functionaliteit in een aparte featurebranch.
- Gebruik Pull Requests voor iedere merge.
- Verwijder featurebranches na een succesvolle merge.
